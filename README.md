# TU IA

Asistente personal de inteligencia artificial desarrollado como proyecto personal.

## Objetivo

Construir progresivamente una IA capaz de conocer al usuario, mantener memoria y ayudarlo con:

- Aprendizaje personalizado
- Organización y planificación
- Objetivos y rutinas
- Proyectos personales
- Toma de decisiones y consejos

## Versión actual

v0.1 — En desarrollo

### V0.1

La primera versión tendrá como objetivo:

- Conversación con un modelo de IA
- Perfil básico del usuario
- Memoria persistente
- Recuperación de recuerdos relevantes
- Control del usuario sobre sus recuerdos
